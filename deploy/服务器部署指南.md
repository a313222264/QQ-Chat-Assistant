# 服务器部署指南（电脑关机，机器人 7×24 在线）

## 原理

机器人在线 = NapCat（挂QQ号的协议端）+ Python 程序 都在运行。搬到云服务器后，与你的电脑彻底解耦：**你关机、睡眠、断网都不影响机器人在群里聊天**。

- 成本：腾讯云/阿里云「轻量应用服务器」2核2G，约 **¥30~60/月**（新用户常有年付特惠，活动价能到 ¥50~100/年）
- 地域选国内（MiniMax / jx3api / 必应国内版全直连）
- 替代方案：家里有旧电脑/树莓派一直开着也行（免服务器钱，但家里断电断网机器人就掉）

## 第一步：买服务器

买「轻量应用服务器」，系统选 **Ubuntu 22.04**，2核2G起步。买完在控制台能看到**公网IP**和 root 密码。

## 第二步：装 Docker（服务器上执行）

Windows 上打开终端（PowerShell）：

```
ssh root@服务器IP
```

登录后在服务器上执行：

```bash
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
sudo systemctl enable --now docker
```

## 第三步：上传代码和配置

**服务器上**克隆仓库：

```bash
cd /root && git clone https://github.com/a313222264/QQ-Chat-Assistant.git
```

**本机电脑上**（另开一个终端，把不入库的三个东西传上去）：

```
scp D:\小编程\qq-assistant\config.yaml root@服务器IP:/root/QQ-Chat-Assistant/
scp -r D:\小编程\qq-assistant\data\memes root@服务器IP:/root/QQ-Chat-Assistant\data\
```

（config.yaml 里有你的 MiniMax key 和 jx3api 令牌；memes 是表情包图库，可选）

**服务器上**改两处配置：

```bash
cd /root/QQ-Chat-Assistant
sed -i 's|ws://127.0.0.1:3001|ws://napcat:3001|' config.yaml   # 指向容器内网的NapCat
nano deploy/docker-compose.yml    # 把 WEBUI_TOKEN= 改成你自己的强密码
```

## 第四步：启动 + 扫码（一次性）

**先放行 6099 端口**：云控制台 → 防火墙/安全组 → 添加规则 → TCP 6099。

服务器上启动：

```bash
cd /root/QQ-Chat-Assistant/deploy
docker compose up -d --build
```

浏览器打开 `http://服务器IP:6099` → 输入你设的 WEBUI_TOKEN → QQ登录页 → 切到「扫码登录」→ 用手机上**东小0（2531285699）**扫码确认。

然后进 WebUI「网络配置」→ 新建 → **WebSocket服务器** → 端口填 **3001** → 保存启用（token留空）。

**扫完码建议把 6099 的公网放行关掉**（下次要扫码时再临时开）。

## 第五步：验证

```bash
docker logs -f qq-bot
```

看到 `已连接 NapCat` 和 `机器人账号：东小0` 即成功。去群里 @东小0 说句话测试。

## 日常运维

| 事项 | 命令 |
|------|------|
| 看机器人日志 | `docker logs --tail 100 qq-bot` |
| 看NapCat日志 | `docker logs --tail 100 napcat` |
| 更新代码后重建 | `cd /root/QQ-Chat-Assistant && git pull && cd deploy && docker compose up -d --build` |
| 全部重启 | `cd deploy && docker compose restart` |
| QQ掉线要重新扫码 | 控制台临时放行6099 → 浏览器扫码 → 关掉放行 |

服务器重启后容器 `restart: always` 会自动恢复，一般无需管。

## ⚠️ 两个重要注意

1. **同一个QQ号只能一处登录协议端**：服务器上线后，**本机的 NapCat/机器人不要再同时运行**（两边会互踢，就是之前"掉线"的那种症状）。本机这套保留作备用：想切回本机时，先 `docker compose down` 停服务器端，再双击桌面启动器。
2. **安全**：WEBUI_TOKEN 必须改强密码；6099 平时不对公网开放；3001 已设计为仅容器内网可达，公网摸不到。

## 常见问题

- **拉镜像慢/失败**：NapCat 镜像在 Docker Hub，国内可能慢。可在 `/etc/docker/daemon.json` 配置镜像加速器（各大云厂商都提供免费加速地址）后 `systemctl restart docker`。
- **内存不够（1G机型）**：NapCat 约占 400~600MB，2G 机型稳妥，1G 可能吃紧。
- **GitHub 克隆慢**：服务器上换 `git clone https://ghfast.top/https://github.com/a313222264/QQ-Chat-Assistant.git`。
